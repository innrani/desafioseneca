# Desafio Científico Sêneca

Aplicação web para a **Feira de Ciências**, onde alunos interagem com estandes por meio de QR Codes e respondem a desafios científicos temáticos.

## Como funciona

1. Cada estande da feira possui um QR Code que direciona para uma página de desafio específica.
2. O aluno responde a uma pergunta de múltipla escolha dentro de um tempo limite.
3. Ao acertar, recebe uma **Chave Científica**.
4. Com todas as chaves coletadas, o aluno desbloqueia o **Desafio Final** e concorre a um brinde.

## Tecnologias

- HTML5, CSS3 e JavaScript puro (sem dependências externas)
- Design responsivo com tema escuro e efeito de campo estelar animado
- Cada página é independente — basta abrir no navegador ou hospedar estaticamente

## Como usar

Basta abrir `index.html` em qualquer navegador moderno, ou servir a pasta com qualquer servidor HTTP estático. Nenhuma instalação ou build é necessária.
